# Big-Timer releases

Signed, notarized builds of Big-Timer, the Big Time Data macOS time tracker.

Download the latest `.dmg` from [Releases](https://github.com/Big-Time-Data/big-timer-releases/releases),
open it and drag Big-Timer to Applications. Installed copies update themselves.

`appcast.xml` is the update feed installed apps read. The release workflow in
`Big-Time-Data/time-tracking` commits to it; don't edit it by hand except to
revert a bad release.
